# contracts — AGENTS.md

Language-neutral contracts between backend, web, desktop and QA. Owner: Nitheesh (approval on everything here).

```
openapi/meno-api.yaml     Generated by springdoc from meno-api (./mvnw -Pexport-openapi, also on ./mvnw verify). Never hand-edit.
openapi/proposed/         Hand-written contracts for endpoints the UI needs before meno-api has them (auth.yaml: invitations,
                          mobile OTP). Delete an endpoint here in the PR that builds it.
test-vectors/gst/         GST cases: intra/inter-state, MRP-inclusive, cess, rounding
test-vectors/pricing/     Discounts (trade, cash, bill-level), price lists, MRP cap
test-vectors/schemes/     Free qty, scheme %, landed cost, suggested PTR
test-vectors/accounting/  Payment allocation, change, credit check, interest, TDS
test-vectors/inventory/   Reorder, expiry status
test-vectors/documents/   Combined distributor bill
reference-data/           Chart of accounts, statutory settings (researched, effective-dated)
sync/                     Sync protocol: JSON schemas for push/pull payloads, conflict codes, versioning
```

## Test vector file format

One JSON file per case group, an array of cases:

```json
[{
  "name": "unique human-readable name",
  "featureId": "GST-01",
  "source": "Prakalya 2026-12-02, confirmed with CA <initials>",
  "input": { },
  "expected": { }
}]
```

All numbers are strings. Values come from Prakalya (confirmed), format from Ashok. Both Java (`TestVectorsTest`) and TS (`billing-engine/tests/vectors.test.ts`) load every file. Changing an existing case's `expected` is a business-rule change → needs Prakalya + Nitheesh approval in the PR.
