# Contributing to MENO

> **Never push to `main` or `develop`.** Create a branch (`feature/<issue#>-name`), push it, and open a Pull Request. No exceptions, including for AI agents. See [docs/team/WORKFLOW.md](docs/team/WORKFLOW.md).

1. Read [AGENTS.md](AGENTS.md) and [docs/team/WORKFLOW.md](docs/team/WORKFLOW.md).
2. Every change starts from a GitHub Issue with acceptance criteria.
3. Branch from `develop`: `feature/<issue#>-short-name`.
4. Conventional Commits: `feat(sales): add batch picker to POS`.
5. Tests + docs in the same PR. Fill in the PR template completely.
6. One approving review from a CODEOWNER, green CI. Releases also need QA sign-off from Ashok.

Using an AI agent? Read [docs/team/AI_WORKFLOW.md](docs/team/AI_WORKFLOW.md). You are responsible for every line the agent writes — read it before you push.
