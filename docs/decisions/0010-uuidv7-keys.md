# ADR-0010: UUIDv7 primary keys

- Status: Accepted · Date: 2026-11-21

## Decision
All primary keys are UUIDv7 generated by the application (Java and TS). Human-readable document numbers are separate columns from number series.

## Consequences
+ Offline devices create ids without collisions; time-ordered → good index locality; ids don't leak counts. − 16-byte keys; fine at our scale.
